# Конструктор валютной платёжной инструкции

Интерактивный макет деталки валютной ПИ (drawer 800 px), собираемой из конфига:
реестр SWIFT-полей + профиль типа сообщения (MT103 / MT202 / MT202COV / MT199).

Все реквизиты, наименования, BIC и счета в макете вымышленные.

Один файл `index.html`, без сборки. Публикуется через GitHub Pages.
