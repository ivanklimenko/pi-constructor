# Конструктор платёжной инструкции

Интерактивный макет деталки платёжной инструкции (drawer 800 px), собираемой из конфига.
Два семейства документов:

- **Валюта** — реестр SWIFT-полей + профиль типа сообщения (MT103 / MT202 / MT202COV / MT199).
- **Рубль** — реестр реквизитов рублёвого документа + профиль вида (платёжное поручение / инкассовое поручение / платёжный ордер):
  hero, блок «Сценарий» (код, S → R, системы Initiator / Source / Destination, ссылки на идентификаторы), транзакции,
  таблица «Отправитель | Получатель» с фиксированным составом строк, назначение платежа и свёрнутые блоки
  (назначение — доп. информация, посредник, бюджетные реквизиты, параметры ED107, параметры инкассового поручения).

Все реквизиты, наименования, БИК, BIC и счета в макете вымышленные.

Один файл `index.html`, без сборки. Публикуется через GitHub Pages.

## Файлы

- `index.html` — конструктор деталки (единственный источник кода drawer: стили + скрипт). Секции «РУБЛЬ: КОНФИГ» и «РУБЛЬ: ОТРИСОВКА» — рублёвое семейство.
- `grid.tpl.html` → `grid.html` — реестр «Валютные документы»; `rub-grid.tpl.html` → `rub-grid.html` — реестр «Рублёвые документы».
  Оба собираются `python3 build.py`, который подкладывает стили и скрипт из `index.html`. Руками `grid.html` и `rub-grid.html` не править.
- `filters.js`, `filters.css` — панель фильтров, вендорена из `vtb-filters/ermo-snapshot/compact-filters.*` (каталог, модификаторы-операторы, чипы «в списке», саджест, сохранённые наборы, импорт). Изменения: конфиг снаружи (`window.CF({root, catalog, defaultIds, demoSets, storageKey, onApply, onCancel})`), палитра на токенах стенда.
- `skeleton.*`, `prompt.*`, `chart.*` — компоненты кита: состояния загрузки, промт подтверждения, график динамики по статусам.
